# **Welcome to MkDocs**


A tool for estimating the original volume of oil in reserves by using an 
object-oriented programming approach (POO).

For full documentation visit [PyTank](https://github.com/ESPOL-FICT-PETROLEOS/PYTANK.git).

## Commands

* `Well` - Create a *well* object.
* `oil_model` - Create an *oil-fluid* model based on PVT data.
* `water_model` - Create a *water-fluid* model based on formation data.
* `Tank` - Create a *Tank* object to perform the desired analysis.
* `Tank` - It allows to perform the respective analysis to determine the POIS.
